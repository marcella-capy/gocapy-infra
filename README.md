# gocapy-infra

Go Capy infrastructure plugin — self-contained tooling for one-time per-client setup work.

## Skills

- **siteground** — create cold email accounts in SiteGround + generate MailToaster-ready import CSVs. Browser-automation JS snippets + ClickUp integration.
- **purchasing-domains-porkbun** — generate cold email sending domain ideas, check Porkbun availability, register, renew, and update nameservers to SiteGround.

## Installation

```bash
/plugins add marcella-capy/gocapy-infra
```

## Companion plugins

- [gocapy-sdr](https://github.com/marcella-capy/gocapy-sdr) — the AI SDR pipeline (research, copywriting, campaign upload, HotHawk/PlusVibe APIs).
- [gocapy-market-intelligence](https://github.com/marcella-capy/gocapy-market-intelligence) — market intel feeds (defense contracts, industry digests).
